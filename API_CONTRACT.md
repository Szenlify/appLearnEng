## 1. Cloudflare R2 Static Cache Contract (`/{hash}.json`)

### 1.1 Hash Generation Algorithm & Word Normalization (Deterministic, Synchronous & Cross-Platform)
Both Mobile (React Native / Hermes) and Backend (Bun) clean punctuation from tapped tokens and compute the file hash identically in `packages/shared/src/hash.ts` using `@noble/hashes` (pure JS, 0 native dependencies, works synchronously in both Hermes and Bun without Node's `'crypto'` module):
```typescript
import { sha256 } from '@noble/hashes/sha256';
import { bytesToHex, utf8ToBytes } from '@noble/hashes/utils';

/**
 * Strips leading/trailing punctuation from a tapped subtitle token
 * while preserving internal apostrophes ("don't") and phrase spaces ("put up with").
 */
export function cleanWordToken(rawToken: string): string {
  return rawToken.trim().replace(/^[^\w']+|[^\w']+$/g, '');
}

export function computeTranslationHash(word: string, sentence: string, targetLang = 'pl'): string {
  const normalizedWord = cleanWordToken(word).toLowerCase();
  const normalizedSentence = sentence.trim().toLowerCase();
  const normalizedLang = targetLang.trim().toLowerCase();
  const rawKey = `${normalizedWord}_${normalizedSentence}_${normalizedLang}`;
  return bytesToHex(sha256(utf8ToBytes(rawKey)));
}
```

### 1.2 Translation Payload Interface (`TranslationResponse`)
Stored in Cloudflare R2 at `/{hash}.json` and returned by `POST /api/v1/translate`:

```typescript
export interface TranslationResponse {
  hash: string;                         // SHA-256 hash
  target_language: string;              // 'pl', 'de', 'es', 'fr', 'it', 'ja', etc.
  selected_text: string;                // The exact word or phrase tapped
  lemma: string;                        // Base dictionary form
  part_of_speech: string;               // e.g. "phrasal verb", "verb", "idiom", "noun"
  ipa: string;                          // Phonetic pronunciation, e.g. "/ˌpʊt ʌp ˈwɪð/"
  cefr_level: 'A1' | 'A2' | 'B1' | 'B2' | 'C1' | 'C2';
  simple_definition: string;            // Simple, concise definition in user's native language
  contextual_translation: string;       // Precise translation of word in this context
  sentence_translation: string;         // Full sentence translation in native language
  context_explanation: string;          // In-depth explanation ("Explain in context")
  example_sentence_en: string;          // Alternative English example
  example_sentence_native: string;      // Native language translation of the example
  created_at: string;                   // ISO 8601 timestamp
}
```

## 2. YouTube Captions Contract

### 2.1 Endpoint: `GET /api/v1/captions?videoId={videoId}&lang=en`
```typescript
export interface SubtitleCue {
  id: string;             // Unique cue ID, e.g. "cue_0"
  start: number;          // In seconds (e.g. 14.25)
  duration: number;       // In seconds (e.g. 2.40)
  end: number;            // In seconds (start + duration)
  text: string;           // Full raw sentence: "I can't put up with this attitude."
  tokens: string[];       // Tokenized words: ["I", "can't", "put", "up", "with", "this", "attitude."]

export interface CaptionsResponse {
  videoId: string;
  language: string;       // e.g. "en" or "a.en"
  isAutoGenerated: boolean;
  cues: SubtitleCue[];
}
```

## 3. Translation Fallback Endpoint

### 3.1 Endpoint: `POST /api/v1/translate`
Invoked **only** when `GET ${PUBLIC_R2_URL}/${hash}.json` returns `404 Not Found`.

**Request Body:**
```typescript
export interface TranslateRequestBody {
  word: string;
  sentence: string;
  targetLang: string; // e.g. 'pl', 'de', 'es', 'fr', 'ja'
  videoId?: string;
}
```

**Response:**
Returns `TranslationResponse` (HTTP 200). The backend simultaneously saves this object to Cloudflare R2 root bucket under `/{hash}.json`.

```typescript
export type CEFRLevel = 'A1' | 'A2' | 'B1' | 'B2' | 'C1' | 'C2';

export interface Flashcard {
  id: string;
  user_id: string;
  type: 'word' | 'sentence';
  target_text: string;           // Word ("put up with") OR Sentence ("I can't put up with this.")

  context_explanation?: string;  // "Explain in context" details

```

## 6. Zod Validation Schemas & Barrel Exports (`packages/shared/src/index.ts`)

Aby AI w żadnym etapie nie musiało zgadywać nazw schematów Zod ani eksportów w pakiecie `@learneng/shared`, główny plik `packages/shared/src/index.ts` eksportuje poniższe schematy i funkcje:

import { z } from 'zod';

export const CEFRLevelSchema = z.enum(['A1', 'A2', 'B1', 'B2', 'C1', 'C2']);

export const TranslationResponseSchema = z.object({
  hash: z.string().length(64),
  target_language: z.string().min(2),
  selected_text: z.string().min(1),
  lemma: z.string().min(1),
  part_of_speech: z.string().min(1),

  context_explanation: z.string().min(1),

  example_sentence_native: z.string().min(1),
  created_at: z.string(),
});

export const TranslateRequestBodySchema = z.object({

  sentence: z.string().trim().min(1, 'Context sentence is required'),
  targetLang: z.string().trim().min(2).default('pl'),
  videoId: z.string().optional(),
